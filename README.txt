ANISSA NOVAL ALIFIANTI — CREATIVE PORTFOLIO

How to open:
1. Extract the ZIP file.
2. Open the folder "anissa_portfolio".
3. Double-click index.html, or open the folder in Visual Studio Code.
4. For VS Code, you can use the Live Server extension and choose "Open with Live Server".

Files:
- index.html : website structure and content
- style.css  : pastel scrapbook styling and responsive layout
- script.js  : mobile navigation, scroll reveal, and project image preview
- assets/    : your profile photo and four design works

Notes:
- Software logos load from Simple Icons CDN, so an internet connection is needed for those logo images.
- Update contact details when you want to add an email or social media link.
